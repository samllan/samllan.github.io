Ultrasound · Research prototype

From echoes to shapes

Can a network learn to reconstruct what made an echo?

Use a simulator where the object is known, collect the received ultrasound waveforms, then investigate whether a neural network can reconstruct the original shape directly.

The aim

Explore learned reconstruction as an alternative to a manually designed reconstruction pipeline.

The work

I explored Field II simulation, radio-frequency waveform processing and PyTorch models that map received signals to an image. The scripts build on Field II examples by Jørgen Arendt Jensen.

What exists

The local archive contains simulation scripts, received-waveform files, model checkpoints, a notebook and a saved training figure. This establishes an exploratory experiment, not a validated imaging system.

The useful insight

Matching a training example is only the beginning. The decisive test is reconstruction of new simulated objects, compared fairly with a conventional method.

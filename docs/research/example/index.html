Question and notes

This fictional pilot shows how the same logbook can track a different project. A small library wants to help booked visitors get seated sooner.

Saved in this browser only.

Input

A fictional reading room pilot and a reusable project structure.

Files that define a logbook project folder
Project fileRole
project.jsonSets project title, description, back link and source repository URL.
goals.jsonDefines the goal hierarchy, narrative stories, tables, revisions and file lists.
leaf_details.jsonHolds per-entry titles, inputs, questions, methods and upstream links.
row_examples.jsonStores captured script outputs and headline metric badges.

Output

Research notes

Copy the example project folder to a new name inside site/research. Set the title, description, back link and source link in project.json. Leave the shared page, CSS and JavaScript in place.

  • Add a question or goal to goals.json. Give it a stable ID and a single sentence about the question.
  • Add what you tried, what you found and what followed under story. Cite the evidence and record when a later entry changes an earlier decision.
  • Add a file to examples and list its filename, date and outcome under the goal. Capture the output of any runnable script in row_examples.json.
  • Add a title and input description in leaf_details.json. Add framing or method when the experiment needs its own explanation. Link earlier entries with from and a goal ID followed by a slash and the filename.
  • Use parent to nest a goal below an earlier goal in its group. Use default_file to choose the experiment readers open when they select a goal.

Use Edit on an experiment to draft question and notes in the browser. To share them, update the entry’s framing in leaf_details.json and rebuild.

Run python tool/build_site.py from the repository root. The build renders any project folder with project.json at research/ followed by the folder name.

Review the decision

The shorter wait is promising enough to justify a better comparison.

What I tried
Compare the medians with the session notes and check what the trial controlled.
What I found
The arrival list ran in the afternoon and the paper list ran in the morning. Time of day may explain the difference.
Next test
Alternate sign-in methods in matching time slots and record both visitor and staff time.

Decision revised · 15 January 2026 (fictional)

Previous decision · Adopt the prepared list after the first pilot.

Why it changed · The groups arrived at different times of day. Alternate the methods in matching time slots before adopting either one.

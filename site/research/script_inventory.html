Script inventory

A guide to the scripts and outputs that represent the research. Published scripts open on GitHub. Proposed entries describe the intended output.

Prepare images and features

ScriptOutput
prepare_image_regions.pyPublished Labelled crop and tile coordinates that show where each region came from in the source image.
compare_image_encodings.pyProposed A table comparing PNG and WebP size and pixel differences for the same generated patches.
learn_image_features.pyPublished Agreement and total loss for two encoded views, showing how duplicating features affects the Barlow Twins objective.
export_feature_vectors.pyProposed A small feature table that keeps each vector linked to its region ID and source coordinates.

ScriptOutput
